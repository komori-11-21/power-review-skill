# `scripts/stage3_log/readers/`：大日志流式读取与行解析器

## 主要实现什么
支撑阶段三底层日志读入、时间范围过滤与文本模板抽取。

## 计划包含的能力
1. **流式文件读取器**（纯通用，不依赖格式）：
   - 按文件路径/目录遍历 `.log` / `.txt` / `.gz` 轮转文件，逐行流式生成（不把几百 MB 文件一次性读入内存）并支持灵活时间范围比较。
2. **模板归一化器**（纯通用，不依赖格式）：
   - 将日志正文中的十六进制地址、IP、动态数字替换成 `<HEX>` / `<IP>` / `<NUM>` 占位符，供差分工具统计高频刷屏模板。
3. **真实行解析与时钟对齐器**（**强依赖真实 `hilog`/`kernel_log` 格式，进内网见真日志后再写**）：
   - 按真实日志列格式拆出时间戳、PID、TID、级别、Tag 与正文；
   - 处理 `hilog` 缺年份日期补全、跨日/跨年边界，以及 `kernel_log` 单调时钟换算为与 `.db` 对齐的墙上时钟。
