# `scripts/stage3_log/`：阶段三（设备日志检索分析总入口）

## 主要实现什么
为大模型提供固定、轻量、流式的本地查日志命令行接口（CLI），避免把几百 MB 原始设备日志塞进对话上下文，将排查聚焦在 `.db` 锁定的异常时间窗与嫌犯上。

## 下级子目录分工
- `readers/`：大文件与压缩分片流式行读取、真实日志格式解析（时间与时钟同步）、文本变量归一化；
- `tools/`：向大模型暴露的 4 个固定查日志核心工具（异常差分、包名转 PID 追踪、条件检索、上下文放大镜）。
- **本级 CLI 入口**：供 Claude 通过 Bash 调用 4 个子命令并以 JSON 输出结果。
