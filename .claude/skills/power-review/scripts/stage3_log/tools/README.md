# `scripts/stage3_log/tools/`：4 个固定查日志小工具

## 主要实现什么
实现阶段三的 4 个高价值局部放大镜工具，供大模型按线索逐步深挖日志根因：

1. **工具 1：异常段 vs 参照段日志差分筛子**（`diff`）：
   - 对比 `Target` 时间窗与 `Ref` 时间窗内归一化后的日志模板频次，筛除两段都在打的噪音，返回只在异常段出现或暴增倍以上（`thresholds.json` 默认 5 倍）的 Top 15 刷屏模板。
2. **工具 2：包名/进程名转 PID 全链路追踪器**（`pid-trace`，**包名 $\leftrightarrow$ PID 发现逻辑需按真实日志或进程快照适配**）：
   - 先跨全局日志或进程快照找出该应用名/进程名关联的全部 `PID`（防止应用重启换 PID 遗漏），再限定异常时间窗统计该 PID 的高频行为模板与报错行。
3. **工具 3：关键词/正则定向检索器**（`search`）：
   - 在指定时间窗内支持按正则、限定 `PID`、限定日志级别（如 `E`/`W`）精准搜出命中行（限制返回条数防爆上下文）。
4. **工具 4：前后上下文放大镜**（`context`）：
   - 给定命中行号或时间戳锚点，流式拉取前后 35 行（可配）完整上下文（可选按 `PID` 过滤），用来追查“有借无还”或等待下游哪个 IPC 服务超时。
