# `scripts/` 总览：脚本流水线架构说明

本目录承载功耗审单 Skill 的工具脚本框架，按四阶段流水线划分模块；遵循 **“通用逻辑先搭、依赖真实结构部分留白待填”** 原则。

## 目录结构与职责总览

| 子目录 | 对应阶段 | 主要职责 | 是否依赖真实 `.db`/日志 |
| :--- | :--- | :--- | :--- |
| `core/` | 公共底座 | 数据模型定义、只读 SQLite 封装、读取 `assets/config/thresholds.json` | 不依赖 |
| `stage1_db/` | 阶段一 | `.db` 探表、电池切片选段、真/模计算、灭/亮屏各维度查询与新表扩展 | **读表 SQL 依赖真库**；切片与合并算法通用 |
| `stage2_evidence/` | 阶段二 | 4 列对比表排版、证据包拼装、知识库双维度案例召回 | 不依赖 |
| `stage3_log/` | 阶段三 | 设备大日志流式读取、行解析与 4 个固定查日志 CLI 工具 | **行解析与 PID 提取依赖真实日志**；流式/上下文/归一化通用 |
| `stage4_evolve/` | 阶段四 | 将复盘确认的新案例卡片与新思路追加写入 `references/` 活文档 | 不依赖 |

## 总入口规划（后续补充）
- 阶段一 + 二总入口（例如 `run_stage1_2.py`）：输入 `.db` 路径与可选参数，串联 `stage1_db` 与 `stage2_evidence` 输出统一证据包 Markdown。
- 阶段三入口在 `stage3_log/`，阶段四归档入口在 `stage4_evolve/`。
