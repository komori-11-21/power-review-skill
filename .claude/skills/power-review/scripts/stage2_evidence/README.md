# `scripts/stage2_evidence/`：阶段二（统一 4 列表证据包与案例召回）

## 主要实现什么
将阶段一算出的各个 `Target` 异常段与 `SlotResult` 格式化为清晰可读的 Markdown 证据包，并自动从知识库抽取出最相关参考卡片，一起交给大模型推理（全部不依赖真库结构）。

## 功能分工
- **本级文件**：
  1. **4 列表格格式化器**：生成统一的表头、切片对比摘要、缺表跳过说明、4 列对比行（标注 `[突增入选]` 与 `Others`）以及调用栈代码块；
  2. **证据包拼装总入口**：遍历全库所有 `Target` 切片，拼出完整证据文档，并触发 `recall/` 附加精确案例与同类示范案例。
- `recall/`：负责解析知识库 Markdown 与执行双维度案例匹配。
