# `scripts/stage2_evidence/recall/`：知识库卡片解析与双维度召回

## 主要实现什么
实现 **“老问题秒杀 + 未知问题照猫画虎”** 双维度召回机制，完全基于本地文本解析与匹配，不依赖 `.db`/日志结构。

## 计划包含的能力
1. **知识库卡片解析器**：
   - 读取 [case_knowledge_base.md](../../../references/case_knowledge_base.md)，切分案例标题、现象类别、关键词以及“① DUBAI怎么看 / ② 日志怎么看 / ③ 结论与转交团队”。
2. **维度 A：精确名字匹配器**：
   - 当本单异常表里抓出的包名、锁标签、IRQ 名直接命中历史卡片时，优先把该卡片召回置顶。
3. **维度 B：按异常维度/槽位同类召回器（照猫画虎核心）**：
   - 当本单出现从未见过的新模块名时，按触发异常的维度类别（例如同属持锁、同属中断唤醒、同属高刷等），自动从知识库抽出 2~3 条历史同类旧卡片，供大模型模仿其“DUBAI $\rightarrow$ 日志”排查套路迁移到新嫌犯身上。
