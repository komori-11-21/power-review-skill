# `scripts/stage1_db/probe/`：元数据探针、缺表降级与未知表扫描

## 主要实现什么
落实 [SKILL.md](../../../SKILL.md) 中的 **表结构自适应（多退少补）** 机制，做到“查询前先探表、缺表不报错、多表主动报”。

## 计划包含的能力
1. **SQLite 元数据自省**（不依赖真库表名，纯通用）：
   - 通过 `sqlite_master` 与 `PRAGMA table_info` 自动获取当前 `.db` 实际存在的全部表与列名清单，供所有查询前检查与给研发/LLM 看库摸底。
2. **缺表/缺字段自动跳过与降级提示**（纯通用）：
   - 目标维度无对应表时生成标准跳过说明，不抛异常中断；缺线程/堆栈表时附带 `hiperf` 线下补抓提示。
3. **全库未知活跃新表扫描器**（`SQL_00_Discovery`，**依赖真库时间格式后填入**）：
   - 排查 `.db` 中未纳入预设槽位、但在异常时间窗内有活跃记录的新表，按列名特征提示应归为“能量型 / 时长型 / 频次极值型”哪一种扩展。
