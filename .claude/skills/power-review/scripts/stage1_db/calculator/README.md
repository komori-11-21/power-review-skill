# `scripts/stage1_db/calculator/`：真/模分层换算与双榜合并去噪

## 主要实现什么
完全不依赖真实表名，纯数学运算模块——严格区分真实物理量与软件模拟估算值，并把任意槽位输出的 `Target` 与 `Ref` 原值汇总为统一 4 列表行。

## 计划包含的能力（均不依赖真实 `.db`）
1. **真/模分层指标计算函数**：
   - `Share %`（同表内部相对占比，绝不把模拟能量直接当真实毫安）；
   - 软件模拟覆盖率 `(SUM(器件能量 mAs) / Δt) / I_real × 100%`；
   - 物理时长占比 `(时长秒 / Δt) × 100%`（用于 AP 深睡率、持锁占比、高刷驻留比、线程 CPU 时间占比）；
   - 真实频次 `次/h` 或 `包/h`（用于 IRQ、Alarm、无线扫描、网络发包）；
   - **累加器减法与缺失语义**：累计递增计数统一做 `段末值减段初值`（不直接 `SUM`），仅靠电量 `%` 反推的电流标为 `[估算值]`，某段没采到的数据一律输出 `无数据`（不把缺失默认填 `0`）。
2. **双榜合并去噪算法**（防排名第 6~10 突增真凶漏网）：
   - 合并 **实测大户榜**（`>= min_threshold`，保底取 `Top N`） $\cup$ **突增榜**（`Target - Ref` 降序 `Top K`，当有 `Ref` 时生效）；
   - 标记 `[突增入选]` 项，将剩余低耗/无突增长尾统一汇总为 `Others（其余 N 项合计）` 行。
