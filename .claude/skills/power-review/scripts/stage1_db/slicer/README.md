# `scripts/stage1_db/slicer/`：电池表切分与异常段/参照段选段

## 主要实现什么
读取全库电池/屏幕/充电真实状态序列，切分出干净有效的灭屏与亮屏放电切片，选出**全部异常切片 (`Target_List`)** 与 **同库最低参照段 (`Ref`)**。

## 计划包含的能力
1. **真实电池序列读取器**（**强依赖真库表结构，回内网对齐后填入**）：
   - 对照真实 `.db` 的电池表/屏幕状态表/充放电表（可能是单表也可能是多表按时间对齐 `JOIN`），统一时间戳单位（转秒）与状态值，输出标准 `BatterySample` 时序列表。
2. **充电与电压回落期过滤**（不依赖真库，纯算法）：
   - 剔除充电状态记录及拔掉充电器后回落干扰窗口（读取 `thresholds.json` 默认 300s）。
3. **连续纯灭/亮屏切片与目标选择**（不依赖真库，纯算法）：
   - 按连续亮/灭屏切出达到最小时长的有效段；
   - 计算每段真实 `delta_mah`、`I_real (mA)`、`掉电率 (%/h)` 及温升（缺 `mAh` 时回退用 `level %`）；
   - 按硬阈值或报障时间窗圈定全部 `Target_List`（均未触发则兜底取掉电最高 1 段），并选出最低 `I_real` 段作为 `Ref`（全库仅 1 段时 `Ref = None`）。
