# `scripts/stage1_db/slots/`：`.db` 各分析维度槽位适配层

## 主要实现什么
定义统一的维度查询接口规范：每个具体查询槽位接收 `target_slice`、`ref_slice` 与只读数据库连接，从真实 `.db` 提取原始度量后，交给 `calculator/` 输出标准 `SlotResult`。

## 目录结构
- 公共基类与统一约定（放在本级）：检查所需真实表是否存在、缺失时自动返回跳过标记、异常时降级提示、调用双榜合并。
- `screen_off/`：灭屏分支各维度槽位实现（`SQL_OFF_1 ~ SQL_OFF_7`）；
- `screen_on/`：亮屏分支各维度槽位实现（`SQL_ON_1 ~ SQL_ON_8`）；
- `custom/`：针对内部专有新表的扩展实现（`SQL_CUSTOM_X`）。

> **重要提醒**：本级下属全部具体 SQL 查询均强依赖内网真实 `.db` 的表结构与累加器/快照语义，对照真库前只保留空壳与适配指引。
