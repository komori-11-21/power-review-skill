# `scripts/stage1_db/`：阶段一（`.db` 切片取证与真/模指标计算）

## 主要实现什么
输入单个功耗 `.db` 数据库，完成“探表 $\rightarrow$ 电池表切分灭/亮屏与圈定异常段 $\rightarrow$ 按各维度提数据并做真/模分层计算 $\rightarrow$ 输出统一 4 列表格数据”。

## 下级子目录分工
- `probe/`：数据库表/列自省探针、缺表自动跳过兜底提示、全库未知活跃新表扫描；
- `slicer/`：充放电与拔充回落期过滤、连续纯灭/亮屏切片拆分、异常段 `Target_List` 与最低参照 `Ref` 圈定；
- `calculator/`：真/模分层指标换算（占比 `Share %` / 覆盖率 / 物理时长占比 / 频次）与双榜合并去噪；
- `slots/`：灭屏、亮屏及自定义新表的具体查询适配器（回内网对照真实 `.db` 表结构后逐个填入）。
